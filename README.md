# 🏨 Hotel Management System

A full-featured hotel management system with **Nobeds channel manager integration**, built with Next.js 15, TypeScript, and Tailwind CSS.

## Features

- **Room & Reservation Management** — real-time availability, booking flow, and calendar view
- **Nobeds Channel Manager Integration** — sync availability and rates across OTAs
- **Guest Management** — profiles, history, and check-in/check-out flows
- **Point of Sale (POS)** — F&B and services billing
- **Dashboard & Analytics** — occupancy rates, revenue charts via Recharts
- **Multi-language Support** — Arabic/English via next-intl (i18n)
- **Role-based Access Control** — admin, receptionist, and manager roles

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | Next.js 15, React 18, TypeScript |
| Styling | Tailwind CSS |
| Forms | React Hook Form + Zod |
| Charts | Recharts |
| i18n | next-intl |
| Deployment | Vercel |

## Getting Started

```bash
npm install
cp .env.example .env.local
npm run dev
```
